# Section controls

The composition editor exposes all existing common-control fields: label, visibility, approved background/width/spacing, text alignment, desktop media alignment, mobile ordering, heading level, animation, anchor, visibility dates, allowed locales and allowed regions. Layout/audience controls are grouped in disclosures to keep the normal editing form short. Empty optional date/anchor inputs remove the corresponding field. Locale and region lists support individual entries/removal and schema-defined limits.

The draft layout preview now allows changing its locale as well as region and timestamp. Scheduling is section visibility only, not a publish/unpublish scheduler. Dates require explicit timezone offsets; visibility is inclusive at the start and exclusive at the end. Invalid intervals, anchors, locales and duplicate page anchors remain save-validation errors. The animation setting is stored but is explicitly not shown by the layout preview.
