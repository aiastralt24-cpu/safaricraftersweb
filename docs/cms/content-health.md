# Content health dashboard

The CMS navigation now includes Content health. The first implemented view lists accessible saved records, their draft/review/publication state, trusted-validation status and error/warning counts. Counts cover loaded records only; the screen explicitly indicates whether more records are available. Selecting a record opens its saved-content checks and trusted findings, with the existing request-trusted-check action where authorized. Publication remains a separate approved action. This screen does not publish or modify content fields.

Migration 263 filters by current view permission before pagination and returns only visible record IDs/cursors. It distinguishes missing validators, unchecked current revisions, expired/version-stale receipts, failed receipts and current passes. Old-revision receipts are not attributed to the current draft. No payloads, hidden-record counts or raw findings are included in the list. Findings are read through the existing permission-checked, exact-revision editor endpoint. Client list responses bind website, ordered IDs and continuation cursor; failures clear prior rows. Account/site changes unmount the workspace and invalidate in-flight results. Selecting another record clears the earlier validation panel. Receipt expiry changes the local status while the page stays open, without network polling.
